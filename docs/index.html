Market Intelligence India

An evidence-first research and market-intelligence terminal for NSE and BSE equities, indices, futures, options and IPOs. Every number it shows carries the calculation, the source, the timestamp and the data status behind it.

What it does

Evidence chains, not verdicts

Every analytical output is a list of items carrying metric, value, weight, calculation, interpretation, source and timestamp. The UI renders "Why?" panels mechanically from those fields, so it cannot display a conclusion the data does not contain.

Mixed is a legitimate answer

When technicals and fundamentals disagree, the confidence engine reports a conflict and the setup generator refuses to produce a direction, rather than manufacturing one.

Status is derived, never permanent

A research card's badge is recomputed from live price on every read. A call whose price has fallen below its entry reads "Not activated" with a negative achieved figure — it never keeps saying BUY.

Document extraction with citations

Reads filings and offer documents, handles Indian number formats and lakh/crore units, and writes citations — page, quote, confidence and its reasons. Nothing enters the fundamentals tables until a human approves it.

Provenance on everything

Values travel in an envelope stamped LIVE, DELAYED, STALE, ESTIMATED, MANUAL, UNVERIFIED, DEMO or UNAVAILABLE. Stale data is never redrawn as live, and seeded demo rows are badged everywhere they appear.

Compliance as configuration

With no registration configured, the platform renders no verification badge and rejects any text containing "guaranteed returns", "risk-free" or similar — enforced by the API before a record can save.

Running it locally

Python 3.11+ and Node 20+. Nothing else — the default configuration uses SQLite and an in-process cache, and the demo dataset seeds itself on first start.

# Backend
cd backend
python -m venv .venv && .venv/Scripts/activate    # Windows
pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:app --reload

# Frontend, in a second terminal
cd frontend
npm install
npm run dev

Open http://localhost:3000. The first account you register becomes the administrator — no default password ships with this project.

Honest limitations

A research tool that hides its own gaps is worse than useless.

  • Nothing is real-time on the default free providers. Every quote is badged DELAYED or STALE.
  • Option chains need a source. The NSE adapter is off by default because NSE's terms restrict automated access; the platform does not work around blocks.
  • No FII/DII flow, index weights or consensus estimates in the free configuration. Those panels say so rather than estimating.
  • No OCR. Scanned filings yield nothing, and the extractor reports that instead of extracting silently.
  • No AI chat assistant and no WebSockets. The structured evidence exists; the conversational and streaming layers do not.
  • Backtests are daily-bar, long-only, single-position.
  • This deployment holds no registration. It is an informational and educational research platform, and says so on every page.
